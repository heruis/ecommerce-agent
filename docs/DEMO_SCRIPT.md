# 3-minute demo script

Goal: in 3 minutes, show a real problem, a working paid product, and AI the grader can trust. Rehearse twice with a timer. Use the **live URL** (after site v2 is deployed, `docs/DEPLOYMENT.md`), a fresh inbox for the sign-up code, a product photo saved on the desktop, a saved Amazon listing with "FDA Approved" in it, a saved removal notice, and the mock-mode local app open as a fallback.

**Before the demo**

- [ ] Site v2 deployed; `docs/AUTH_SETUP.md` done (custom SMTP, confirm email, templates); the inbox receives the code
- [ ] Live eval run done today with the deployed models (golden, audit, appeal); numbers on the last slide
- [ ] Test account has credits; Stripe in test mode; webhook endpoint healthy
- [ ] Evidence library has the SGS report; the Amazon listing and the removal notice are in a text file to paste
- [ ] Photo ready (a real product shot on a busy background shows the main-image warning best)
- [ ] Browser zoom 125%, notifications off, second tab with the trace page preloaded
- [ ] Fallback: local `pnpm dev` in mock mode with the same examples (works offline; mock mode cannot see photos or translate, and says so)

**If something fails live:** say what happened, switch to the fallback tab, and point at the trace — showing how you debug is part of "AI design".
