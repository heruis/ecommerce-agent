# 3-minute demo script

Goal: in 3 minutes, show a real problem, a working paid product, and AI the grader can trust. Rehearse twice with a timer. Use the **live URL**, a fresh test account, and keep the mock-mode local app open as a fallback.

| Time      | Who  | Screen                                                               | Say (short)                                                                                                                                                                                                                                                                                                                                                    |
| --------- | ---- | -------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 0:00–0:25 | Lead | Landing page                                                         | "Chinese sellers list on Amazon US with supplier copy like _FDA认证，100%安全，美国销量第一_. Translated literally, that gets listings suppressed. ChatGPT translates the violation faithfully. ListWise localizes **and** checks every claim."                                                                                                                |
| 0:25–0:40 | WS4  | Sign up → dashboard (3 free runs)                                    | "Real accounts on Supabase, 3 free runs."                                                                                                                                                                                                                                                                                                                      |
| 0:40–1:20 | WS1  | New listing → _Example: silicone cup_ → Generate                     | Narrate the stream: "guardrails screen the input… extraction pulls facts with source quotes… the localization agent drafts, calls our rule engine, fixes the title… the compliance agent searches our policy knowledge base."                                                                                                                                  |
| 1:20–2:00 | WS2  | Compliance table + score                                             | "Three restricted claims, each with a cited source. FDA doesn't approve cups, so 'FDA approved' becomes 'made with food-grade silicone'. 'Eco-friendly' was rewritten automatically by our policy gate. Score **85 vs 45** for their current listing, and the trace shows every model call, tool call and its cost." Click **View agent trace** for 5 seconds. |
| 2:00–2:20 | WS3  | Edit title, type "FDA approved", save → warning; Export CSV          | "Every edit is re-checked. One click to export."                                                                                                                                                                                                                                                                                                               |
| 2:20–2:45 | WS4  | Billing → Upgrade → Stripe test checkout (4242…) → back with 50 runs | "Stripe test mode; credits are granted only by the verified webhook, idempotently."                                                                                                                                                                                                                                                                            |
| 2:45–3:00 | Lead | Architecture slide or README diagram                                 | "Next.js on Vercel, Supabase, Stripe, Claude. Evals: X/Y golden cases live, retrieval recall 0.9+. Next: TikTok Shop and bulk import."                                                                                                                                                                                                                         |

**Before the demo**

- [ ] Live eval run done today with the deployed models; numbers on the last slide
- [ ] Test account has 0 runs used; Stripe in test mode; webhook endpoint healthy
- [ ] Browser zoom 125%, notifications off, second tab with the trace page preloaded
- [ ] Fallback: local `pnpm dev` in mock mode with the same example (works offline)

**If something fails live:** say what happened, switch to the fallback tab, and point at the trace — showing how you debug is part of "AI design".
