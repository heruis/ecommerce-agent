# 3-minute demo script

Goal: in 3 minutes, show a real problem, a working paid product, and AI the grader can trust. Rehearse twice with a timer. Use the **live URL**, a fresh test account, a product photo saved on the desktop, and keep the mock-mode local app open as a fallback.

| Time      | Who  | Screen                                                                                                                 | Say (short)                                                                                                                                                                                                                                                                                                                                                    |
| --------- | ---- | ---------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 0:00–0:20 | Lead | Landing page                                                                                                           | "Chinese sellers list on Amazon, TikTok Shop and Shopify with supplier copy like _FDA认证，100%安全，美国销量第一_. Translated literally, that gets listings suppressed, and every site wants different fields. ChatGPT translates the violation faithfully. ShelfPass gives one checked report with every field each site asks for."                          |
| 0:20–0:30 | WS4  | Sign up → dashboard (3 free runs)                                                                                      | "Real accounts on Supabase, 3 free runs."                                                                                                                                                                                                                                                                                                                      |
| 0:30–1:05 | WS1  | New listing → _Example: silicone cup_ → all three channels ticked → add the photo → **Generate report**                | Narrate the stream: "guardrails screen the text and check the photo file… extraction pulls facts with source quotes… the photo check looks at the background and text… now three localization agents run in parallel, one per marketplace, each calling its own rule engine… one compliance agent reviews all three drafts against our policy knowledge base." |

**Before the demo**

- [ ] Live eval run done today with the deployed models; numbers on the last slide
- [ ] Test account has 0 runs used; Stripe in test mode; webhook endpoint healthy
- [ ] Photo ready (a real product shot on a busy background shows the main-image warning best)
- [ ] Browser zoom 125%, notifications off, second tab with the trace page preloaded
- [ ] Fallback: local `pnpm dev` in mock mode with the same example (works offline; mock mode cannot see photos and says so)

**If something fails live:** say what happened, switch to the fallback tab, and point at the trace — showing how you debug is part of "AI design".
